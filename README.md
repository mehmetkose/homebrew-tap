# mehmetkose/homebrew-tap

Homebrew formulae for [lokal](https://github.com/mehmetkose/lokal): real `.lokal` and `.local` domains with
valid HTTPS for every service you run in development, on macOS.

```console
$ brew install mehmetkose/tap/lokal
$ lokal setup
```

After `brew upgrade lokal`, run `lokal upgrade` so the background service switches to the new version. Before
`brew uninstall lokal`, run `lokal uninstall`.

`Formula/lokal.rb` is generated by lokal's release workflow each time a release is published, from
[`packaging/homebrew/lokal.rb.in`](https://github.com/mehmetkose/lokal/blob/main/packaging/homebrew/lokal.rb.in).
Don't edit it here; change the template in the lokal repository instead.

Report problems in [lokal's issue tracker](https://github.com/mehmetkose/lokal/issues).
